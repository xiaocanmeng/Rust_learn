# MCP 基础概念与工作原理

## 1. 什么是 MCP
MCP（Model Context Protocol）是一种让模型能够安全调用外部工具的协议。它提供统一的接口，让模型无需直接处理 HTTP API 等底层细节。

## 2. 工作原理概览
- **Host（模型）**：解析用户意图，选择调用工具。
- **Connector（MCP 服务器）**：将工具调用映射到真实外部 API，例如 GitHub API。
- **外部服务**：执行实际操作，如读写仓库文件、创建 PR 等。

## 3. 基本调用流程
1. 用户用自然语言描述需求。
2. 模型决定调用哪个工具，并生成参数。
3. Connector 接收调用并与外部服务通信。
4. 外部服务返回结果。
5. 模型继续处理或进行下一步调用。

## 4. 使用场景
- 自动化 GitHub 文档管理
- 自动创建 PR / Issue
- 自动化仓库维护
- 为学习或实验环境提供统一的模型控制能力
